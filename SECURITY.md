# Reporting security concerns

Proofline is a synthetic, single-user local demo. Read [the application boundaries](docs/SECURITY.md) before testing it. Do not expose it through a tunnel or use real incident data.

Use GitHub's **Report a vulnerability** action on this repository's [Security page](https://github.com/ripleyforge/proofline/security) for a private synthetic reproduction. If that action is unavailable, open an issue containing only a request for a private reporting channel. Do not publish vulnerability details, credentials, personal records, or real logs in an issue, pull request, or screenshot.

The owner reviews reports without a promised response time or certification claim.
